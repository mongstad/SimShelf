# SimShelf v0.1.0.17 — Experimental pre-release

**Draft for owner review; not published.** Release target:
`d0d606987f3d588deaa8043ce905a3f94a170884`. Publication is on hold pending the
[readiness findings](../validation/issue-64-release-readiness.md). This document
prepares release copy; it does not authorize a tag, upload or visibility change.

**Your simulations, one library.** SimShelf is a free, local-first Python simulation
library and run journal. Register and run existing scripts from a local browser,
retain terminal/editor recording, inspect arguments, source context, notes,
screenshots and copied or referenced results, and optionally preserve selected
source and modest results in a separate shared local Git archive.

> **Experimental software:** SimShelf is in early development. Bugs, incomplete
> preservation, incompatible updates and data loss are possible. Keep independent
> backups of original sources/results, your SimShelf library and any external Git
> archive. Reference-only files and the external archive are not included in a
> library backup. Independently verify measurements and captured outputs before
> using them for research.

## Intended downloads and installation

After separate owner approval, the release is intended to be marked **Pre-release**,
not stable. GitHub will provide source-code ZIP/tar archives for the approved tag.
The separately built assets are:

- `simshelf-0.1.0.17-py3-none-any.whl` — installable Python wheel, bundled local UI.
- `simshelf-0.1.0.17.tar.gz` — Python source distribution, including guides/examples.
- `SHA256SUMS.txt` — SHA-256 digests for those two assets.

There is no standalone desktop executable and no PyPI publication is proposed.
The wheel's platform-neutral filename does not certify Windows/macOS support.
The corrected sdist includes all three README gallery PNGs, unchanged. Candidate
artifacts come from packaging-fix commit `d0d6069`, not earlier accepted main.
[Current checksums](v0.1.0.17-d0d6069-SHA256SUMS.txt) identify the new bytes;
previous candidate checksums remain historical and must not be used for these files.

For a downloaded wheel, explicitly create a **new** dedicated environment outside
any source project/library. From the directory containing the downloads:

```bash
sha256sum -c SHA256SUMS.txt
python3 -m venv /path/to/new-simshelf-env
/path/to/new-simshelf-env/bin/python -m pip install ./simshelf-0.1.0.17-py3-none-any.whl
/path/to/new-simshelf-env/bin/simshelf --version
/path/to/new-simshelf-env/bin/simshelf --workspace /path/to/new-library ui
```

Replace paths deliberately. Dependencies normally require network access during
installation; normal local operation does not. Installing the sdist instead of
the wheel additionally needs Python build dependencies. Neither command provisions
a simulation's scientific dependencies. Choose its existing trusted interpreter.
The installed CLI does not include the checkout's `start.sh`; use the command above.

For the GitHub source archive, extract it and follow
[Getting Started](https://github.com/mongstad/SimShelf/blob/d0d606987f3d588deaa8043ce905a3f94a170884/docs/GETTING_STARTED.md).
That workflow uses `./start.sh --setup` explicitly. Python **3.11+** is declared;
current candidate testing used Fedora 44/Python 3.14.8 and Chromium. Git is optional
for basic recording, required for Git integrations. Node is not needed to run the
packaged portal. Use new disposable data first, not your research library.

## Data and compatibility

Workspace backups contain source snapshots and retained managed copies, not every
external input/output or the separate Git archive. Local Git commits do not upload
anything. Git is appropriate for source/configuration and modest text results,
not a general-purpose store for large changing binary scientific files.

Application version, user-declared scientific version, exact source snapshot,
source Git revision and archive commit are distinct. Reproducibility is not
promised. Optional run removal, screenshot deletion and progress enablement have
explicit schema-upgrade boundaries; older builds may not open upgraded libraries.
Never run older writers against such libraries. See the
[data guide](https://github.com/mongstad/SimShelf/blob/d0d606987f3d588deaa8043ce905a3f94a170884/docs/DATA.md).
This release preparation itself changes no schema or scientific records.

## Known limitations

- [#59](https://github.com/mongstad/SimShelf/issues/59): adding an incomplete output
  declaration can produce an empty-path error and hide capture-path review.
  Declarations do not redirect writes; inspect actual paths and do not assume
  placeholder text is a saved value.
- [#60](https://github.com/mongstad/SimShelf/issues/60): moving a registered source
  folder has no supported relocation UI. Keep the original location available;
  preserved copies remain readable, but external references may be unavailable.
- [#61](https://github.com/mongstad/SimShelf/issues/61): generated files count toward
  the 1,000-entry source inventory bound and can block archive consent despite
  small selections. This is distinct from the per-run archive storage budget;
  never delete valuable results merely to pass the inventory check.
- Linux/Chromium is the validated combination. Other OS/browser combinations,
  Python/Git version matrices, GPU workloads and long/high-volume runs are not
  certified. Single-user localhost only; no remote hosting/synchronization,
  automatic scientific-package installation or universal progress detection.
- Publication remains subject to explicit owner approval of historical developer
  paths and screenshot content, including the partially visible local path in
  `03.png`. Packaging correction does not grant permission to make the repository public.
